# Ảnh màn hình của hướng dẫn sử dụng

Thư mục này chứa ảnh màn hình dùng trong `docs/huong-dan-su-dung.md`.

Danh sách 17 ảnh cần chụp, tên tệp và cảnh cần chụp: xem mục **Phụ lục — Danh sách ảnh màn hình**
ở cuối `docs/huong-dan-su-dung.md`. Trong thân tài liệu, mỗi chỗ cần ảnh có một dòng
`<!-- ảnh: … -->` mô tả đúng cảnh phải dựng trước khi chụp.

Quy ước khi chụp:

- Chạy hệ thống bằng `docker compose`, dùng dữ liệu mẫu tự tạo. Không dùng dữ liệu thật.
- Tên đơn vị đặt là "Đảng ủy Phường X" cho thống nhất giữa mọi ảnh.
- Chụp đủ chiều ngang màn hình để thấy cả menu trái.
- Định dạng `.png`, tên tệp đúng như bảng trong phụ lục.
